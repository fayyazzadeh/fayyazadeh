## 👋 درباره پروژه

این مخزن کد وب‌سایت شخصی **رامین فیاض‌زاده** است؛ فضایی برای معرفی سوابق حرفه‌ای، مهارت‌ها، تجربه‌های کاری و فعالیت‌های تخصصی در حوزه فناوری اطلاعات.

تمرکز اصلی وب‌سایت بر شبکه و زیرساخت، مدیریت سرورها، مجازی‌سازی، پشتیبانی فناوری اطلاعات و توسعه وب است.

## ✨ بخش‌ها و امکانات وب‌سایت

- **معرفی و رزومه:** معرفی حرفه‌ای و خلاصه‌ای از مسیر کاری
- **مهارت‌ها:** شبکه، زیرساخت، سرورها، مجازی‌سازی و پشتیبانی IT
- **سوابق کاری:** تجربه‌های شغلی و مسئولیت‌های حرفه‌ای
- **فعالیت‌ها و دوره‌ها:** فعالیت‌های تخصصی و دوره‌های آموزشی
- **فرم تماس:** امکان ارسال پیام از طریق وب‌سایت
- **ویکی:** بخش محتوایی و گفت‌وگوی مرتبط با ویکی سایت

## 🧰 فناوری‌های استفاده‌شده

| فناوری | کاربرد |
| --- | --- |
| [Next.js](https://nextjs.org/) | فریم‌ورک اصلی وب‌سایت |
| [React](https://react.dev/) | ساخت رابط کاربری |
| [TypeScript](https://www.typescriptlang.org/) | توسعه کد با نوع‌دهی ایستا |
| [Node.js](https://nodejs.org/) | محیط اجرای ابزارها و اسکریپت‌ها |

| [Cloudflare Turnstile](https://www.cloudflare.com/application-services/products/turnstile/) | کمک به جلوگیری از ارسال خودکار و مخرب فرم‌ها |
| [Resend](https://resend.com/) | زیرساخت ارسال ایمیل |

## 🔐 امنیت و نگهداری

امنیت وب‌سایت بخشی از فرایند توسعه و نگهداری آن است. در کد فعلی، مواردی مانند اعتبارسنجی درخواست‌های ورودی، استفاده از Cloudflare Turnstile برای فرم‌های عمومی و ارسال تیکت، و هدرهای امنیتی HTTP در نظر گرفته شده‌اند.

برای مشاهده جزئیات بررسی‌ها، تصمیم‌های امنیتی، موارد انجام‌شده و کارهای باقی‌مانده، راهنمای زیر را ببینید:

📘 **[راهنمای فارسی امنیت و نگهداری وب‌سایت](docs/security-hardening-fayyazzadeh-ir-fa.md)**

> نکته: وجود مستندات امنیتی به‌معنای پایان همه آزمون‌های عملی یا تضمین امنیت کامل سامانه نیست. وضعیت هر اقدام در راهنمای امنیتی مشخص شده است.
