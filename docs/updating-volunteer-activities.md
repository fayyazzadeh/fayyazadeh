# به‌روزرسانی فعالیت‌های داوطلبانه

اطلاعاتی که در بخش «فعالیت‌های داوطلبانه» سایت نمایش داده می‌شوند در فایل
[`data/volunteer-activities.json`](../data/volunteer-activities.json) نگهداری می‌شوند.

## ویرایش از طریق GitHub

1. فایل `data/volunteer-activities.json` را در GitHub باز کنید.
2. روی آیکون مداد (**Edit this file**) بزنید.
3. برای افزودن فعالیت، یک شیء جدید با دو فیلد `title` و `date` به آرایه اضافه کنید.
4. برای اصلاح، مقدار همان فیلد را تغییر دهید؛ برای حذف، شیء مربوط به آن فعالیت را بردارید.
5. از **Commit changes**، تغییر را روی شاخه‌ای جداگانه ثبت کنید و Pull Request به `master` بسازید.
6. پس از موفقیت Build و بررسی پیش‌نمایش، تغییر را ادغام کنید. انتشار Production فقط با تأیید مسئول سایت انجام شود.

## قالب داده

هر فعالیت باید این دو فیلد متنی را داشته باشد:

- `title`: عنوان فعالیت
- `date`: تاریخ یا بازهٔ زمانی نمایشی

نمونه:

```json
{
  "title": "عضو تیم اجرایی یک رویداد",
  "date": "۱۴۰۴ · ۲۰۲۵"
}
```

نکته‌ها:
- هر مورد داخل آرایه با ویرگول از مورد بعدی جدا می‌شود؛ بعد از آخرین مورد ویرگول نگذارید.
- متن فارسی و تاریخ‌ها همان‌طور که باید روی سایت دیده شوند وارد شوند.
- JSON باید معتبر بماند؛ قبل از انتشار، Build پیش‌نمایش را بررسی کنید.
- سایت فعالیت‌ها را خودکار مرتب می‌کند: موارد دارای «تاکنون» ابتدا می‌آیند، سپس سال شمسیِ شروع فعالیت به‌ترتیب نزولی (جدیدتر به قدیمی‌تر) مرتب می‌شود؛ لازم نیست ترتیب فایل را دستی تغییر دهید.
